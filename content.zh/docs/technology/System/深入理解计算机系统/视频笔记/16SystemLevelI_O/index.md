# Unix I/O概括

用文件(一堆二字节序列)来描述很多抽象的事物，比如I/O设备，打字机；网络连接(套接字)，消息是写入套字节传送，读取套字节接收；

![](img/ly-20250529121931900.png)  

文件还有个属性：读取位置；网络套接字不允许在时间上跳转，只能在数据包进入时对其进行读或写  

# 文件类型
文件、目录、套接字(作为发送和接收)、应用程序之间接收发送（视频不讲）  
符号链接（多指针指向同一文件等）

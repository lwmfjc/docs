在 C++ 中，-> 运算符有一个独特的“递归”特性。当你写下 entity->Print() 时，编译器会查看 entity 的类型：
- 如果 entity 是原生指针：它直接解引用并访问成员。
- 如果 entity 是一个对象（类实例）：
	1. 编译器会调用你重载的 operator->()。
	2. 这个函数必须返回两样东西之一：要么是一个原生指针，要么是另一个重载了 -> 的对象。
	3. 编译器拿到返回的指针后，自动再次对它使用箭头操作，直到找到最终的成员。

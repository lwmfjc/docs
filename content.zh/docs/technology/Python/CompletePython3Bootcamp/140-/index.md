# CSV

CSV 代表逗号分隔变量（comma separated variables），它是电子表格程序中非常常见的输出格式。   

示例：   

姓名，工时，费率（Name, Hours, Rate）   

David, 20, 15   

Claire, 40, 20

> 用记事本打开，而不是Excel关联打开，就能看到所有的逗号分隔了

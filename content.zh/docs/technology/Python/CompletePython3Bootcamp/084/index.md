> pypi是一个开源第三方Python包的仓库，相当于 Ruby中的RubyGems、PHP的package，Perl的CPAN，以及**Nodejs的NPM**。

> 目前只用Python自带的两个库：Python的**标准库或内置库** ~~比如math数学库~~ ，也称为**包**

```bash
Python
│
├── 内置功能（Built-in）
│   ├── print()
│   ├── len()
│   ├── list
│   ├── dict
│   ├── int
│   └── ...
│
└── 标准库（Standard Library）
    ├── os
    ├── sys
    ├── math
    ├── datetime
    ├── json
    ├── re
    └── ...
```
